## Implementation

DrawingCanvas keeps the existing Pointer Events, one pending stroke, pointer capture, logical coordinates, canonical DrawingStroke, tools, history and PNG export architecture. A native labelled input-method select is separate from answer mode and pen/eraser tools.

Standard accepts mouse, pen and touch. Stylus priority returns on pointerdown when pointerType is touch, before pending ink or capture. Mouse, pen and empty/unknown pointer types retain existing primary-pointer/button checks. Every move/up/cancel/lostcapture requires the accepted pending pointerId. Rejected primary touch cannot append, capture, interrupt or flush an active pen; no width/height heuristics are used. Selecting a preference does not update strokes or answers.

The canvas-frame/drawing-canvas scope applies touch-action:none, user-select:none, -webkit-user-select:none and -webkit-touch-callout:none. Only the canvas cancels contextmenu through its normal React event path. Toolbar and application text remain outside this protection.

The client helper stores learnforge:drawing-input-mode with standard/stylus. Default or invalid values resolve to standard. Reads/writes catch storage failures; the selected state continues for the mounted canvas. No network/user-profile persistence.
