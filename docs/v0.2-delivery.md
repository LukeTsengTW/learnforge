## 2. Auth architecture

`AuthService` 統一 signup、login、logout、restore、hint；`AuthProvider` 訂閱 session 變化並用 request generation 避免過時的 restore 回覆更新目前帳號。Auth callback 不 await 其他 Auth 方法，避免 SDK lock 死鎖。

typed client 啟用 session persistence／auto refresh，停用不需要的 URL session detection；所有 client 要求有 15 秒 timeout。恢復時以 `getUser()` 驗證 session，再讀自己的 profile。refresh token 失敗／撤銷／已過期會離開受保護頁面，cache 不刪除；短暫網路失敗且 session 尚未到期時可使用本機進度。

註冊欄位只有 Username、Password、Confirm Password、Password Hint；client 驗證長度、格式、密碼一致、提示必填，提示包含完整密碼時拒絕。使用者密碼只交給 Auth，不寫入 application tables／metadata／logs。畫面包含「密碼提示僅用於協助你回想密碼，無法重設密碼。」及「請勿直接把密碼寫在提示中。」

Home 公開；quiz/result 需要登入，保存並限制 intended destination 為 app 內 quiz/result 路徑。Auth UI 有 loading、錯誤訊息、登出與 normalized username。缺環境設定時顯示清楚 configuration error，不顯示 stack trace。

## 3. Database schema

- `profiles`：UUID PK → auth.users cascade；唯一 normalized username；created_at／updated_at。
- `password_hints`：user UUID PK/FK；1–200 字元非空 hint；timestamps。
- `attempts`：UUID PK、user FK、quiz／revision、draft/submitted、started/client_updated/submitted 時間、deterministic score/max/count cache；唯一 `(user_id,quiz_id)`，並有 updated_at index。user/quiz unique index 同時支援 user lookup。
- `answers`：UUID PK、JSONB answer、可選 JSONB grade、timestamps；唯一 `(attempt_id,question_id)`、user index、複合 parent ownership FK；保留 drawing stroke model。
- `private.hint_rate_limits`：非公開 API schema 的 durable rate counters。額外表僅服務本次 password-hint 防濫用需求。

分數與 grade 不是可信正式成績。載入 submitted attempt 時由原 `decodeAttempt()` + `gradeQuiz()` 重算，不盲信 DB numeric／JSON。

## 5. RLS policies

所有 application tables 與 private limiter 啟用 RLS。

- Profiles：authenticated 只可讀 `id = auth.uid()` 的 profile。
- Attempts：authenticated 自己的 SELECT／INSERT／UPDATE／DELETE；寫入有 WITH CHECK，不能冒用別人 UUID。
- Answers：answer.user_id 必須是 auth.uid，parent attempt 也必須屬於該 uid；RLS + composite FK 雙重限制。
- Hints／limiter：沒有一般 client policy，預設拒絕；server service role 在必要範圍操作。

未使用 broad `USING (true)`。own-data policy 明確排除 null identity。profile 建立只由固定 search_path 的 private security-definer trigger 執行，id 來自 `NEW.id`。

## 6. Grants

明確 revoke PUBLIC／anon／authenticated 的 table 預設權限，再只授予：

- authenticated：profiles SELECT、attempts／answers SELECT/INSERT/UPDATE/DELETE、save RPC EXECUTE。
- anon：沒有 application table 讀寫或 privileged hint RPC 權限。
- service_role：profiles／hints SELECT、private limiter 所需操作、hint RPC EXECUTE。
- PRIVATE trigger functions 撤銷 PUBLIC／anon／authenticated EXECUTE；save/hint RPC 使用 security invoker，不繞過 caller RLS。

已直接用資料庫角色測試，不只檢查 SQL 字串。

## 7. Username → synthetic email

共用 pure functions：trim + lowercase → `^[a-z0-9_]{3,24}$` → `<username>@users.learnforge.invalid`。例如 ` LuKe_123 ` 變成 `luke_123`。前端與 Edge 共用同一份 identity logic；DB constraints 與 profile trigger 另行驗證 normalized 值及 email 一致性，SQL 實測拒絕尾端換行。

linked demo 已確認 signup／Email provider 啟用，`mailer_autoconfirm=true`；實際註冊立即取得 session。沒有 email 欄位或可收信地址。

## 8. Password hint implementation

只有一個公開 Edge Function：`password-hint`。`verify_jwt=false`；只接受單一 username JSON、POST/OPTIONS，streaming body 最多 1 KiB。成功回傳只有 `{hint:string|null}`，失敗回傳固定訊息；不返回 user UUID、email、profile 或 database error。

函式使用 Edge runtime 內建 server credential，呼叫 service-only RPC，先消耗 durable atomic budgets 才查詢 hint。每 15 分鐘：username 3 次、hashed IP 10 次、global 100 次。超額 429／Retry-After: 900；no-store。global budget 仍限制偽造或輪替 forwarded IP；沒有 bulk API。過期 counters 定期於 request 中清除。

這不是密碼重設。知道 username 的人可取得提示，UI 有告知不要填敏感資訊。有限次查詢仍可能推測 username 存在，基本限流不等於完整反爬／抗 DoS。

## 9. Attempt persistence architecture

保留 v0.1 QuizAttempt／QuestionAnswer domain。`AttemptRepository` 提供 async load/save/delete；Local 與 Supabase implementation 負責 DTO mapping。React 只用 context/store；parser／grader／drawing engine 不直接呼叫 SDK。

save RPC 同一 transaction 更新 attempt 和所有 answers，expected UUID／server updated_at 作 CAS。DB trigger 鎖定 submitted header 與 answers；answer writes lock parent，避免提交與答案同時更新。restart 只有成功刪除正確 remote version 後才移除 cache；失敗保留原 submission。

本機即時保存、雲端 800ms debounce、同時僅一個 save，提交立即排程。drawing 保留 stroke JSON；不因每次 pointer move 發 request，不上傳 PNG。寫入中的新輸入會接續批次保存。account store 在帳號切換時隔離／dispose，RPC 再驗證原 account owner。

## 10. Local/cloud synchronization rule

cache：`learnforge:attempt:v2:<user-id>:<quiz-id>`，schemaVersion 2 envelope 內仍是 domain schemaVersion 1。v0.1 key 與 repository 保留，舊資料由登入使用者明確選擇匯入，且原資料保留。

同代 draft 較新 valid updatedAt 勝、相同時間 remote 勝；submitted 勝 draft；兩份 submitted 保留 remote immutable submission。UUID 變更／遠端已刪除表示 restart，新一代 remote 優先；新裝置空 draft 不覆蓋已有 remote。JSONB object key 順序不影響等價判定；array／stroke 順序仍重要。

覆蓋衝突的有效本機內容前先寫 `...:recovery:<uuid>`；若勝出的本機作答即將取代另一裝置獨立修改的雲端草稿，也先備份該雲端版本。備份失敗則保留原狀。格式不符的本機原始資料也先備份再載入雲端。Malformed remote 不被空草稿覆蓋。offline／DB failure 保留 cache 並顯示重試訊息；online event／重試按鈕恢復。Storage 本身不可用時仍可使用 cloud 並提示風險。

沒有 Realtime；其他分頁／裝置變更在下一次同步或 refresh 合併。client clock 仍影響新舊比較。recovery 目前需透過 DevTools Local Storage 匯出，沒有管理 UI。

## 18. Known limitations / 未實作

- Demo synthetic email 沒有 password reset、email delivery 或帳號復原。Hint 可被知道 username 的人查詢；basic quota 可能被耗盡，還沒有 CAPTCHA。
- 每帳號／quiz 一份 current attempt；restart 會刪除該份 cloud attempt，沒有歷史列表。recovery JSON 僅本機、需手動匯出，沒有自動清理。
- 非 Realtime、非逐題協同合併；client clock 影響較新判定。錯誤 remote revision 保留並通知，不自動遷移未知內容。
- 離線能力限已載入頁面，不是 PWA。尚未同步的內容仍受 browser storage 容量、清除資料及裝置遺失影響；離線不允許破壞性 restart。
- 自主練習採 client deterministic grading，不是防作弊／正式成績平台；計算與 drawing 仍 manual。
- 無 OpenAI、AI grading/hints、Vision、AI quota、多題庫、analytics、admin、quiz editor、cloud image upload、leaderboard、social、PWA 或 SSR。
- GitHub Pages workflow 已支援 build-time 公開 env variables，但本次未發布 Pages；未在此環境驗證 Docker local stack。
- 本次 v0.2 變更留在 working tree，未另外 commit／push。
