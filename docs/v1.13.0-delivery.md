## Request and human decisions

Human 的需求：「修改所有題目的評分標準（計算題的部分），目前來說都太過嚴格了，需要放寬標準，寫出答案就可以直接給分。另外題庫『離散數學習題 Ch1、Ch3、Ch5、Ch7、Ch8』的部分，把裡面的『講義』改成『習題解答』。」

調查後以一次結構化提問請 human 決定三件事，三項都選了建議的選項：

1. 放寬方式：逐小題——每一小題的最終答案正確（等價寫法、未化簡也算）就給該小題全部分數，不要求過程；答案錯時仍依 rubric 給部分分數並從寬判斷。改在所有計算題共用的正式評分規則，各題 rubric 文字不改；畫圖題不變；只影響之後的提交，已提交的分數不重算。
2. 用詞：直接修改現有的 `discrete-math-exercises-2026` revision 1，不建立新版本。
3. 發版前以一次付費的 AI 評分實際驗證新規則（provider canary）。

## Investigation

- 正式提交的計算題由 submit-quiz 依題呼叫 AI 評分：打字作答用 `SUBMISSION_CALCULATION_INSTRUCTIONS`，手寫作答用 `SUBMISSION_HANDWRITTEN_CALCULATION_INSTRUCTIONS`（v3 的舊版本題庫也用前者）。原本的規則只為看得見的過程給部分分數、不假設省略的步驟、「猜對答案不得過程分」。各題的 rubric 依步驟配分，AI 必須逐項回報 criterion 的分數。
- Current 題庫中有 58 題計算題，其中 25 題分小題（含封存版本共 64 題計算題、27 題分小題）；分小題的題目中，每一項 rubric criterion 都以小題標號開頭，只有 `discrete-math-ch3-set-theory-examples` q02 有一項不標小題的概念 criterion。
- 編修現有 revision 的文字：提交時伺服器送出的 manifest 含 reference answer 與 solution 文字，但 `finalize_ai_grading_v4_submission` 只檢查型別、不保存；保存的評分紀錄綁定 criterion id 與配分，不綁文字；沒有任何內容、manifest 或 prompt 的雜湊。草稿、已提交的結果與草稿儲存都不受影響；已提交紀錄重開時會顯示新的文字。

## Design

- `supabase/functions/_shared/calculation-grading.ts`：新增 `LENIENT_CALCULATION_SCORING`，同時嵌入打字與手寫的正式評分 instructions。規則：
  - 先依小題切分：以 (a)、(b) 等標號開頭的 criterion 屬於該小題；沒有小題的題目整題為一個小題；分小題的題目中不標小題的 criterion 屬於整題。
  - 最終答案與該小題的參考答案數學上等價就算正確，包括未化簡的式子、等價形式、正確的數值或不同但正確的記號；沒有答案、答錯，或同時寫出互相矛盾的多個答案都不算正確。要求求解、計算、計數或求出值、式子、公式的小題，即使也要求完整推導或過程，最終答案仍是那個結果。要求證明題目中給定的敘述成立的小題，證明本身就是最終答案，只重寫要證明的敘述或結論不算正確。
  - 最終答案正確時，該小題的每一項 criterion 給滿分，即使沒有寫過程；所有小題的最終答案都正確時，整題的 criterion 也給滿分。
  - 否則依看得見的作答從寬給分：接受等價的方法與記號，不因不影響方法的小錯扣分。空白或無關的作答 0 分。
  - 手寫另規定：只計看得清楚的內容，無法辨識的最終答案不算正確。
  - Rubric 仍決定 criterion 的 id、順序與配分；防 prompt injection 的文字不變。
- `src/content/quizzes/discrete-math-exercises-2026/v1.quiz.md`：19 處「講義」：18 處改為「習題解答」，說明中的「習題解答講義」刪去「講義」。題目標題的「（ChN 講義第 X 頁）」改為「（ChN 習題解答第 X 頁）」；說明中的「五份習題解答講義…沿用原講義」改為「五份習題解答…沿用原習題解答」（避免「習題解答講義」變成重複的字）；「講義答案為 $63$」改為「習題解答的答案為 $63$」。題號、配分、答案、rubric 不變。
- `supabase/functions/_shared/quiz-context.generated.ts`：重新產生；只有這個題庫的 13 筆 context 改變。

## Known limitations

- 模型依新規則給分只有一次 production canary 的證據（打字、單一小題、只寫最終答案，得到 6 / 6）。分小題、手寫、證明題、互相矛盾的答案在 production 沒有驗證，只有指令文字與測試。AI 評分仍可能誤判。
- 只寫最終答案就能拿到該小題的滿分；題庫的答案本來就隨網站打包，這是自主練習，不是防作弊的考試。
- 習題題庫的說明仍寫「請寫出完整推導並說明所用的計數原理或定義」，與新的給分方式不一致（不影響給分）。
- 直接修改 revision 1：已提交的紀錄重開時顯示新的用詞。
- 第一章與第三章例題題庫的題目標題仍寫「講義」。
- 舊版已提交作答的 advisory 重新評分仍使用原本的規則。
