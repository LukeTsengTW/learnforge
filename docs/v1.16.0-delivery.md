## Independent verification

`verify_ch5.py`（scratchpad，以 `python -I` 執行，不讀題庫檔，也不讀轉寫檔）以列舉或公式重算 53 項，53/53 PASS：

- q01–q03：$A\times B$、$B\times A$、$B^2$ 逐元素相符；六個關係都是 $A\times B$ 的子集合、大小 0、1、2、3、3、6；列舉 $A\times B$ 的全部子集合為 64 個；小的 $m,n$ 下 $2^{mn}$ 相符。
- q04：四個序對滿足 $n=7m$；遞迴 $(0,0)\to(1,7)\to(2,14)\to(3,21)$。
- q05：定理 5.1 四個等式在三元素宇集的全部 512 組 $(A,B,C)$ 成立。
- q06、q07、q10：$f$ 是函數，$\mathscr{R}_1$ 缺 3、$\mathscr{R}_2$ 的 2 重複；$f(A)=\{w,x\}$；$f_1$、$f_2$ 映成，$g(A)=\{x,y\}$。
- q08：$m\le n\le5$ 的一對一函數全列舉，個數等於 $n!/(n-m)!$；$m>n$ 時為 0。
- q09：$g(0)=g(1)=0$。
- q11–q14：$4^7$ 個函數中映成者 8400，兩種上限的公式都是 8400；各項 16384、8748、768、4；$S(7,4)=350$（集合分割列舉）；$\operatorname{onto}(4,3)=36$，三塊分割恰為題庫列出的六種；$m\le6$（公式到 $m\le7$）時 $\operatorname{onto}(m,n)=n!\,S(m,n)$。
- q20：六列以窮舉分別得到 81、36、14、6、15、3；$S(4,1..3)=1,7,6$；$\binom{n+(m-n)-1}{m-n}=\binom{m-1}{m-n}=\binom{m-1}{n-1}$。
- q15–q19：餘數恰 36 種；五個鴿洞分割 $\{1,\ldots,9\}$，84 個 6 元素子集合都含和為 10 的兩數，例子只有 $(2,8)$；69、60、63、62，例子同和 23，$\{1,\ldots,14\}$ 的全部 3,003 個六元素集合都有兩個子集合同和；100 個鴿洞分割 $\{1,\ldots,200\}$，$\gcd(n,n+1)=1$，例子 101 個數中只有 $\{99,100\}$ 同洞。

## Risk, classifier and deployment order

`release:classify --base v1.15.0 --head HEAD --include-working-tree`：**security-ai／Risk C／providerCanaryRequired=false**。Risk C 的原因：`quiz-context.generated.ts` 為 Database or Edge behavior；package files 與 `.env.local`（未追蹤，不會 commit）為 unrecognized path。沒有 provider、grading、prompt 的變更，不需要 provider canary；不需要 migration。

部署順序（已依此執行，結果見下文「Candidate commit, CI, Edge and Pages」）：

1. 合併到 master 與 exact candidate CI。
2. 六個使用 generated context 的 Edge function 各部署一次：`ai-tutor`、`ai-grade`、`ai-drawing`、`ai-responses`、`save-quiz-draft`、`submit-quiz`；runtime health。
3. 一次 exact-SHA Pages dispatch。
4. Production public smoke：release identity 1.16.0、Library 5 份題庫與新卡片、新題庫的 Student／Answer Preview。

Edge 先於 Pages：先部署 Edge 時，舊的 Pages 不列出新題庫，使用者看不到差異；若先部署 Pages，新題庫在 Edge 同步前無法儲存草稿（`save-quiz-draft` 依 context 驗證）、提交或使用 AI。
