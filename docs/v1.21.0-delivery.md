## Correctness and editorial policy

Check each question from definitions, arithmetic and sufficient conditions, rather than trusting the printed key. Correct demonstrable source errors; label added assumptions or rewritten alternatives explicitly. Do not invent the author's intended text. Keep question identities, chapter order, scores and all original numerical data. Explanations document every substantive departure; source tables are transcribed as labeled lists supported by the existing Markdown renderer.

Primary educational references consulted directly:

- [OpenStax, price elasticity](https://openstax.org/books/principles-economics-3e/pages/5-1-price-elasticity-of-demand-and-price-elasticity-of-supply): percentage elasticity differs from a curve's unit-dependent slope. Finite changes below are derived algebraically using the midpoint definition.
- [OpenStax, consumption choices](https://openstax.org/books/principles-economics-3e/pages/6-1-consumption-choices): allocation by marginal utility per dollar; added assumptions distinguish continuous interior conditions from discrete purchases.
- [OpenStax, monopolistic competition](https://openstax.org/books/principles-microeconomics-3e/pages/10-1-monopolistic-competition): many firms with differentiated offerings, including restaurants, location and service differences. Applying that definition to the breakfast-shop example is an instructional classification, not an empirical market study.

Substantive changes from the supplied commit:

The existing input renderer labels by index while results label by option ID; sequential renumbering keeps both views consistent. - `ch1-q7`: narrow the broad government-role question to the property-rights institution. Welfare and public services could also answer the original broad wording.
- `ch2-q4`: specify elasticity throughout the relevant interval, other conditions fixed and revenue rather than profit.
- `ch2-q9`: define the exercise's「薄利多銷」as raising revenue by reducing price; do not imply that elasticity alone establishes higher profit.
- `ch2-q10`: retain (c), but repair the other alternatives. With a 10% price fall, revenue falls iff quantity growth `g < 1/9` (about 11.11%), not necessarily below 10%. Midpoint elasticity is `19g/(2+g)`. Comparing curve steepness requires normalized price/quantity coordinates and the interval's secant, not raw slopes across different goods.
- `ch3-q2`: replace original (b)'s ambiguous monetary opportunity-cost claim with an explicitly false comparison of utility units to money. The solution discloses the replacement; (d) remains correct.
- `ch3-q5`: add the continuous, interior MU-per-dollar equality assumption. With indivisible portions, the original observations do not uniquely imply MU = 10.
- `ch3-q7`: state fixed non-labor inputs and `Q(0)=0`; the table alone cannot establish short run. Preserve the nine observations in aligned labeled lists.
- `ch3-q10`: present the original table's rows as labeled lists and state additive utility and integer-hour allocation; the original 18 MU entries are unchanged. The existing renderer does not support GFM pipe tables, so no global rendering change or new dependency was introduced.
- `ch4-q2`: distinguish short-run fixed firms from long-run entry and state constant industry costs. Change the unmatched currency dollar sign to「12 元」to avoid malformed math.
- `ch4-q8`: define「劣勢」as strict dominance; a weakly dominated action can tie as a best response in a Nash equilibrium.
- `ch4-q10`: ask for the continuous-output shutdown threshold/infimum of 6; clarify that strictly positive optimal output requires `P > 6`, while `P = 6` gives `q = 0`. State `VC(0)=0`.
