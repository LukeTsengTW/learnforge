## Known limitations

- AI grading remains a learning reference and can be mistaken; canonical exam answers/rubrics do not certify provider accuracy.
- Formal calculation grading depends on the backend canonical context. Provider/evidence failures keep attempts draft/retryable.
- Stored results use their original grading version and persisted evidence; historical attempts are not regraded.
- Bundled answers are part of a static practice product, not a secure examination system. Author remains a local editor/import/preview/export tool, not a server-side CMS.
- This revision supports text calculations only. Only existing demo/v2-handwriting declares handwriting; no new capability or drawing/provider algorithm is added.
- Existing browser/local validation is not a new full production verification. **No full v1.5 production verification exists yet.**
