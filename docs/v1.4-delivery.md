## Product contract

- `#/library` 僅以 `quizCatalog.current` 為可見題庫與標籤／科目選項的 authority；archived revisions 不加入結果。
- 標籤取自完整 current catalog 的 `tags`，科目取自 `subject`，動態產生去重選項；其他有效篩選不縮減選項來源。
- 題型使用既有 `QUESTION_TYPE`／`QUESTION_LABEL`：單選題、多選題、是非題、填空題、計算題、畫圖題。每個類別都是 single-select，預設「所有標籤／所有科目／所有題型」代表該維度不限制。
- 搜尋只比對題庫 metadata：`title`／`description`／`subject`／`tags`；trim 周圍空白，Latin 文字不區分大小寫，純空白等同沒有搜尋限制。
- 搜尋與所有有效篩選採 AND；題型條件在題庫中 **任一題** 的 `questions[].type` 相符即成立。Filtering 僅移除不符項目，保留來源 catalog 順序。
- Canonical answers、solutions、rubrics、hints 及其他 grading authority 不參與搜尋。
- 篩選／搜尋沒有符合題庫時顯示空狀態與「清除篩選」。重設清空搜尋、恢復三個預設選項及完整 current catalog，focus 回到搜尋；無有效限制時不顯示不必要的 reset control。
- 桌面為左側 filters／右側 search；窄版 reflow 為堆疊 controls。已驗證 360 × 800 手機 viewport 沒有水平 page overflow，原生 selects／search input 保有 labels、鍵盤巡覽與可見 focus。

本功能是 client-side frontend／domain filtering，不新增 backend endpoint、schema／migration、Edge Function 變更、Auth policy、AI／provider 行為或 dependency。Library 搜尋不讀取 canonical grading authority；原有 practice／resume routing、草稿保存、current／archive 與歷史評分契約維持。不需要 provider canary，也沒有執行 canary。

## Known limitations

- 搜尋是 metadata substring matching，沒有 fuzzy search、full-text ranking 或 server search。
- Filters 為 single-select；current catalog 僅三份題庫。
- Authenticated smoke 沒有完整 network trace，不宣稱逐一捕捉全部 request。
- Responsive、label、鍵盤與 focus 檢查屬 accessibility-oriented UI evidence，不是 WCAG certification。
- 既有 backend／grading 限制仍由 [v1.3 delivery](v1.3-delivery.md#known-limitations) 記錄；v1.4 沒有新增 backend version audit 或 grading canary。
