## 2. Architecture

```text
raw .quiz.md
  -> parseQuiz()
  -> canonical Quiz / Question union
  -> Question renderer
  -> typed QuestionAnswer / QuizAttempt
  -> pure reducer + deterministic grading
  -> immutable submitted result
  -> Result / correct answer / solution / rubric
```

Parser、grading 與 reducer 不依賴 React；`App.tsx` 只負責路由與組裝。狀態透過小型 external store、Context 與 `useSyncExternalStore` 提供，沒有 Redux。答案與筆畫的單一來源為 domain attempt，工具與提示開關留在 UI。

## 3. Quiz Markdown DSL

`@quiz id="demo"` 加上 `# 標題` 定義測驗。每題使用 `:::question id="q1" type="single" points="2"`，以 `:::end` 關閉；可含 `:::options`、`:::answer`、`:::hint`、`:::solution`、`:::rubric`、`:::drawing`。一般 Markdown、inline／block LaTeX 與 fenced code 可共存。

選項範例：`- [x] b | $AB$`。Parser 驗證唯一 id、屬性格式、題型、正分數、非空題幹、正確選項數量、solution、rubric 總分、drawing 寬高與未關閉區塊；未知內容不會靜默忽略。錯誤含行號與可辨識的題號。

完整 grammar、限制與各題型範例已寫在 [README DSL specification](../README.md#quiz-markdown-dsl-specification-v1)；完整範例現位於 [v1.quiz.md](../src/content/quizzes/demo/v1.quiz.md)。

## 4. 六種 question type

| 題型 | 作答 UI | 提交後 |
| --- | --- | --- |
| 單選 | Radio，同組只能選一個 | 自己／正確答案、文字正誤與解析 |
| 多選 | Checkboxes | 完整集合比對、自己／正確答案與解析 |
| 是非 | True／False Radio | Boolean 嚴格比對 |
| 填空 | 文字 input | exact 或 case-insensitive 比對 |
| 計算 | Multiline textarea，保留完整推導 | manual、學生答案、參考答案、solution、rubric |
| 畫圖 | Responsive Canvas 與工具列 | manual、唯讀 drawing、文字參考答案、solution、rubric |

計算與畫圖明確顯示：「此題型將於後續版本提供 AI 參考評分，目前請自行對照參考解答。」

## 5. Grading 規則

`gradeSingleChoice()`、`gradeMultipleChoice()`、`gradeTrueFalse()`、`gradeFillBlank()`、`gradeQuiz()` 均為純函式。

單選與是非嚴格相等；多選使用集合相等，不考慮順序、沒有部分給分。填空的 exact 保留大小寫與空格差異，case-insensitive 只忽略大小寫；空白文字視為未作答。錯答與未作答分開計數。

Demo 客觀題最高 **10 分**，計算 6 分與畫圖 4 分全部排除於 score、maxScore 與客觀題計數。手動題回傳 `status: "manual"`、score/maxScore 為 null，結果頁明確說明不納入自動評分。

## 6. Drawing Canvas

800 × 600 固定 logical coordinate，pointer position 依實際 DOM rectangle 換算並 clamp；CSS resize 只改顯示尺度。筆畫存 `tool / color / width / points`，支援滑鼠、觸控、觸控筆、黑紅藍、筆寬、復原／重做與確認清除。

Canvas 以 stroke replay 重繪；橡皮擦使用 destination-out。PNG utility 回傳本機 Blob，再觸發下載，補白底、不上傳。已實際驗證匯出的 PNG signature、**800 × 600** 尺寸與筆畫內容。

## 7. localStorage strategy

`learnforge:attempt:v1:<quiz-id>`，資料含 schemaVersion、quiz revision、時間、typed answers 與狀態。只序列化 domain DTO；每次完成作答操作同步儲存，提交保存 cloned answers 與結果。重新整理可恢復草稿及結果；回到 Quiz route 不會解鎖提交。Restart 需明確確認，並移除原 key。

載入時驗證資料與題庫版本，重新計算 submitted score；損壞、版本不符、容量或存取失敗都有可讀通知。沒有雲端同步與多分頁衝突處理。
