## Drawing behavior and feature review evidence

`penWidth`（預設 4，range 1–24）與 `eraserWidth`（預設 24，range 4–40）各自保留設定。Toolbar 依工具顯示「筆寬」／「橡皮擦大小」，native range 有 label、數值與鍵盤操作。建立 stroke 才選用對應尺寸；既有 `DrawingStroke { tool, color, width, points }` 與 eraser `destination-out` 完全沿用。

Preview 是獨立 DOM UI state，與 pending drawing stroke 分離；`pointer-events: none`、`aria-hidden="true"`，不進 bitmap、stroke/history 或 PNG，也不新增 commit／pointer capture。Overlay 使用 border-box 與 inset 對比環，外部 footprint 對應真正 eraser diameter。

Pointer 位置先由 `getBoundingClientRect()` 映射到 config.width/config.height 的 logical coordinates；overlay 的 left/top 與 width/height 再用 logical／config 的百分比投影到 Canvas 顯示尺寸。例：logical eraser width 40，Canvas 顯示為 50% 時，preview diameter 為 20 CSS px；水平與垂直各自按 config 比例換算。

Mouse hover 時顯示；接受 mouse stroke 後，pointerup 使用最後座標保留 preview，尺寸回到目前 eraserWidth；pointerleave／pointerout 或離開 bounds 時隱藏。Pen／touch 接觸期間可見，pointerup／cancel 後隱藏；pen 後續 hover event 可恢復。Stylus input mode 仍在建立 pending stroke／capture 前拒絕 touch。

保留 Apple Pencil rapid strokes、reused pointerId、delayed lostpointercapture 與 flush/commit-once 的既有 ownership／capture 邏輯。Supervisor Diff review 曾要求修正 mouse pointerup 後 preview 消失與 content-box／outer shadow 擴大外徑；兩項修正及 regression tests 完成後，supervisor 才核准 feature commit 與 normal push。
