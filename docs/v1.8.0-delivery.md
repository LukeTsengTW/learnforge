Canonical constants 在 `src/models/drawing.ts`，UI 與 client／Edge stored parser 共用。100-width 可經 browser replay、controlled answer、draft/submission、server parsing／raster／PNG flow；101-width 在 stored validation 拒絕。Pen UI max 24 與 stored structural max 100 是不同 contract。

Preview 是與 pending stroke 分離的 DOM/UI-only state：`pointer-events: none`、`aria-hidden="true"`，不進 Canvas bitmap、stroke/history、replay 或 PNG，也不額外建立 stroke／commit／capture。Border-box＋inset ring 的外部邊界代表真正 erase diameter。

Logical-to-CSS projection 不變：pointer 依 `getBoundingClientRect()` 與 config.width/config.height 映射 logical coordinates；overlay 按相同比例定位／縮放。直徑 = eraser logical width × displayed Canvas width / logical Canvas width（height 亦按 config.height 比例）。100 logical 在 50% 顯示時為 50 CSS px，不是固定 CSS eraser。

Mouse hover／move／contact 顯示 preview，pointerup 後保留最後位置並回到目前 eraserWidth；leave／out 隱藏。Active contact 使用 stroke width snapshot，slider 改變不覆寫該 snapshot。Pen／touch 接觸結束後隱藏，pen 後續 hover 恢復；stylus mode 在 pending stroke／capture 前拒絕 touch。Apple Pencil rapid strokes、reused pointerId、delayed lostpointercapture、pending／controlled acknowledgement 與既有 ownership 邏輯均保留。Code／controlled browser evidence 不等於真實裝置驗收。
