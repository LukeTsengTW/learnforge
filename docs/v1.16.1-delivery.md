## Risk, classifier and deployment order

`release:classify --base v1.16.0 --head HEAD --include-working-tree`：**security-ai／Risk C／providerCanaryRequired=false**（generated context 為 Database or Edge behavior；package files 與未追蹤的 `.env.local` 為 unrecognized path）。沒有 provider、grading、prompt 的變更；不需要 migration。

部署順序：

1. 合併到 master、`release:check --require-clean`、strict preflight、exact candidate CI。
2. 六個 Edge function 各部署一次：ai-tutor、ai-grade、ai-drawing、ai-responses、save-quiz-draft、submit-quiz；runtime health。
3. 一次 exact-SHA Pages dispatch；public smoke。

Edge 先於 Pages。先部署 Edge 時，舊的 Pages 仍以 revision 1 為 current，而 revision 1 的 context 仍在新的 Edge 中，所以沒有影響。若先部署 Pages，revision 2 在 Edge 同步前無法儲存草稿、提交或使用 AI。

## User-visible consequences

- 第五章題庫顯示 18 題、總分 136 分、約 100 分鐘。
- 已提交的 revision 1 紀錄仍對應 revision 1（它的題目與 context 都保留）。
- 已有 revision 1 草稿的使用者開啟題庫時，`get_or_create_quiz_draft` 依使用者與 quiz id 取回既有的草稿（不分 revision），頁面以草稿的 revision 1 顯示，並提供既有的「捨棄舊草稿並使用最新版重新開始」按鈕（`QuizPage.tsx`，在草稿 revision 不是 current 時顯示）；繼續作答或提交 revision 1 都可以，因為 revision 1 的 context 仍在 Edge。沒有草稿的使用者會建立 revision 2 的草稿。release-canary 帳號在 v1.16.0 留下的第五章草稿就是 revision 1 草稿。
