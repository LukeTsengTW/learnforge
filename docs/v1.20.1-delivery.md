## Scope

The application header now renders a build-time `__APP_VERSION__` constant injected from the repository's `package.json`. The constant is also declared in `src/vite-env.d.ts`. `vite.config.ts` resolves `package.json` relative to the config module, so the value does not depend on the shell's current working directory.

This patch changes only the frontend display and release metadata. It does not change quiz content, database migrations, Supabase Edge Functions, authentication, or runtime APIs. The next Pages build is expected to display `v1.20.1` and publish a manifest with the exact deployed closure SHA.
