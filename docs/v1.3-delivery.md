## Product contract

目前 demo revision 為 `demo/v2-handwriting`，calculation 題透過 `:::drawing` 宣告打字＋手寫。封存的 `demo/v1-7d7c900e` 保留原文字計算題，供歷史結果按 exact revision 重建。

Capability 取自 **實際載入的精確版本**，不使用最新版本替換歷史。只有含宣告 drawing 能力之 calculation 的 revision 選用 schema2/v4；目前四個 bundled revisions 中恰一個具備此能力，不是所有計算或 DrawingQuestion 都自動升級。

schema2 `CalculationAnswerV4` 同時保留 `type / mode / text / strokes`。切換模式不刪除 inactive buffer；正式評分只用 selected mode：文字模式排除 inactive strokes，手寫模式排除 inactive text。schema1/schema2 共存，不回溯改寫歷史。

DSL parser 保留 drawing dimensions **100–2000** 的歷史範圍；v4 publication 另要求 **100–1200**，配合實際 server raster 限制及 scored-rubric validation。不能把 1200 當成所有歷史 parser 的上限。

## Draft persistence

`get_or_create_quiz_draft` 開啟 capable revision 時，server 可仍回傳 schema1。Client 在記憶體 promote 至 schema2，不因單純開啟題庫就寫入 server；實際 edit 後才啟動 normal autosave。

schema2 只經 authenticated `save-quiz-draft` 保存：平台 `verify_jwt=true`，handler 驗證 user context、ownership、exact revision、answer shape 及 `expectedUpdatedAt` CAS，再呼叫 service-only `save_quiz_attempt_v4`。成功回應必須包含 `answerSchemaVersion=2`。Browser 不直接呼叫 privileged RPC，失敗亦不 fallback 至 legacy v3 writer；衝突／不可用保留草稿及既有 recovery 行為。

## ai-grading-v4

正式提交只提供 `requestId / attemptId / expectedUpdatedAt`。Server 依 owned draft 的 schema 與 exact revision 決定版本、模型、canonical question/rubric、answer hash 與分數。非 v4-capable schema1 新提交保留 v3 路徑；schema2 用 v4。

文字 calculation 使用 active text；手寫 calculation 驗證保存的 active strokes，由 server rasterize，再送 **calculation rubric/provider path**。它不是 generic drawing analysis；DrawingQuestion 仍有自己的 drawing grading 路徑，browser PNG 不是正式 authority。

Active-only answer hash 排除 inactive buffer。Rubric criterion IDs、各項上限、得分、criteria sum 與總分皆須驗證，才可由 service-only finalization 原子保存。fill 的 blank/rule-match、calculation/drawing 的 system unanswered 不需要 provider；server-visible blank 可保存 `raster_blank` bookkeeping，不能把 failed blank ledger row 計為 provider execution。

Formal grading 使用 `gpt-6-luna`、`reasoning.effort=medium`、Responses API Structured Outputs、`store=false`。它使用 private system ledger，與 personal Tutor 20-credit quota 分離。Result/History/Analytics/Mistakes 重建 persisted v4 judgments，不為讀取或重新載入重跑 grading；submitted evidence 保持 immutable。

## Security / privacy boundaries

Browser 不能提供正式 grading authority；server-owned exact revision/rubric、service-only persistence/finalization 與 active-only evidence 是邊界。Vector strokes 仍保留為帳號答案資料，正式手寫評分使用 server raster，不把 browser image 當權威。

Production public bundle 已有 Turnstile site configuration，真實 public signup 已驗證；本輪未重讀 server CAPTCHA/bypass flags 或重做 missing/invalid-token 拒絕，不能把 positive signup 當新的全面 enforcement 證明。詳見 [Security](../SECURITY.md)。

AI 是學習參考，`store=false` 不保證 provider 零 retention。LocalStorage/browser-profile、JWT expiry 與 shared-device 風險仍存在；formal grading 不扣 Tutor quota，不代表不會送出外部 AI processing。見 [privacy](privacy.md)。Release canary data 保留，任何 cleanup 需另行明確授權。

## Known limitations

- 手寫辨識可能錯誤；drawing 必須使用 pointer/touch/stylus，沒有純鍵盤繪圖或 teacher/exam-grade accuracy 保證。
- 目前 shipped catalog 只有一個 v4-capable revision，不能把其他歷史 calculation 宣稱為手寫支援。
- Provider、raster 或 evidence validation 失敗可讓提交保持 draft/retryable；沒有強制以零分完成失敗提交。
- Original BS4 legacy 503 live probe 未執行；typed-v4 replacement 已關閉指定 runtime/auth/persistence requirement。
- GitHub Pages 任意 response-header 限制、未加密 localStorage 與歷史版本保存要求仍存在。
- Accepted leaked-password advisor WARN 保留；沒有在本輪修正或變更方案，沒有安全／隱私認證。
