# 布林代數基礎

練習布林運算、德摩根定律與常見邏輯閘。每題都可以先自行推理，再對照解答。

:::question id="identity" type="single" points="2" tags="identity-laws"
### 恆等律
哪個式子對所有布林值 $A$ 都成立？
:::options
- [ ] a | $A+0=0$
- [x] b | $A+0=A$
- [ ] c | $A\cdot1=1$
- [ ] d | $A\cdot0=A$
:::solution
$0$ 是 OR 的單位元，因此 $A+0=A$；$1$ 是 AND 的單位元，因此 $A\cdot1=A$。
:::end

:::question id="demorgan" type="multiple" points="3" tags="de-morgan,identity-laws"
### 選出所有恆等式
以下哪些式子對所有 $A,B$ 都成立？
:::options
- [x] a | $\overline{A+B}=\overline A\,\overline B$
- [x] b | $\overline{AB}=\overline A+\overline B$
- [x] c | $A+\overline A=1$
- [ ] d | $A\overline A=1$
:::solution
前兩式是德摩根定律；第三式是互補律。$A\overline A$ 永遠等於 $0$。
:::end

:::question id="absorption" type="true-false" points="1" tags="absorption"
### 吸收律
$A+AB=A$ 對所有布林值 $A,B$ 都成立。
:::answer
true
:::solution
$A+AB=A(1+B)=A\cdot1=A$。
:::end

:::question id="idempotent" type="fill" points="2" match="case-insensitive" tags="identity-laws"
### 冪等律
請填入單一英文字母：$A+A=\underline{\qquad}$。
:::answer
A
:::solution
OR 的冪等律是 $A+A=A$。
:::end

:::question id="nand" type="single" points="2" tags="logic-gates,nand"
### NAND 輸出
兩輸入 NAND 閘在哪一組輸入時輸出 $0$？
:::options
- [ ] a | $(0,0)$
- [ ] b | $(0,1)$
- [ ] c | $(1,0)$
- [x] d | $(1,1)$
:::solution
NAND 是 AND 的反相；AND 僅在 $(1,1)$ 輸出 $1$，因此 NAND 僅在這組輸入輸出 $0$。
:::end

:::question id="xor" type="multiple" points="2" tags="logic-gates,xor"
### XOR 輸入
哪些輸入使 $A\oplus B=1$？
:::options
- [ ] a | $(0,0)$
- [x] b | $(0,1)$
- [x] c | $(1,0)$
- [ ] d | $(1,1)$
:::solution
XOR 在兩輸入不同時輸出 $1$，所以選 $(0,1)$ 與 $(1,0)$。
:::end

:::question id="double-negation" type="true-false" points="1" tags="complement"
### 雙重否定
$\overline{\overline A}=A$。
:::answer
true
:::solution
對布林值取反兩次會得到原值。
:::end
