# 離散數學：關係

以有限集合上的具體例子辨認自反、對稱、傳遞與偏序，並練習關係合成。

:::question id="reflexive" type="single" points="2" tags="reflexive"
### 自反關係
在 $X=\{1,2\}$ 上，$R=\{(1,1),(2,2)\}$ 是否自反？
:::options
- [x] a | 是，因為 $X$ 中每個元素都與自己有關係。
- [ ] b | 否，因為缺少 $(1,2)$。
- [ ] c | 否，因為缺少 $(2,1)$。
:::solution
自反只要求 $(1,1)$ 和 $(2,2)$ 都在 $R$ 中；此關係符合。
:::end

:::question id="universal" type="multiple" points="3" tags="reflexive,symmetric,transitive"
### 全關係
在 $X=\{1,2\}$ 上，$R=X\times X$ 具有哪些性質？
:::options
- [x] a | 自反
- [x] b | 對稱
- [x] c | 傳遞
- [ ] d | 反自反
:::solution
所有有序對都在 $R$ 中，因此自反、對稱且傳遞；它包含 $(1,1)$ 與 $(2,2)$，所以不反自反。
:::end

:::question id="symmetry" type="true-false" points="1" tags="symmetric"
### 對稱的定義
若 $R$ 對稱，則對任意 $a,b$，只要 $(a,b)\in R$，就有 $(b,a)\in R$。
:::answer
true
:::solution
這正是對稱關係的定義。
:::end

:::question id="equivalence" type="fill" points="2" match="exact" tags="equivalence"
### 等價關係
等價關係須自反、傳遞，還須具備哪一種性質？請填「對稱」。
:::answer
對稱
:::solution
等價關係同時具有自反、對稱、傳遞三種性質。
:::end

:::question id="transitivity" type="single" points="2" tags="transitive"
### 檢查傳遞性
在 $X=\{1,2,3\}$ 上，$R=\{(1,2),(2,3)\}$ 是否傳遞？
:::options
- [ ] a | 是，因為關係中只有兩個有序對。
- [x] b | 否，因為缺少 $(1,3)$。
- [ ] c | 否，因為缺少 $(3,1)$。
:::solution
由 $(1,2)$ 與 $(2,3)$，傳遞性要求 $(1,3)$ 也在 $R$ 中；它並不存在。
:::end

:::question id="partial-order" type="multiple" points="3" tags="partial-order"
### 偏序條件
偏序關係必須具備哪些性質？
:::options
- [x] a | 自反
- [ ] b | 對稱
- [x] c | 反對稱
- [x] d | 傳遞
:::solution
偏序的定義是自反、反對稱、傳遞；不要求對稱。
:::end

:::question id="empty-symmetric" type="true-false" points="1" tags="symmetric"
### 空關係
非空集合上的空關係 $\varnothing$ 是對稱的。
:::answer
true
:::solution
空關係沒有任何 $(a,b)$ 需要檢查，所以對稱條件真空成立。
:::end

:::question id="composition" type="fill" points="2" match="exact" tags="composition"
### 關係合成
若 $R=\{(1,2)\}$、$S=\{(2,3)\}$，請以 `(1,3)` 格式填出 $S\circ R$ 唯一的有序對。
:::answer
(1,3)
:::solution
先經 $R$ 從 $1$ 到 $2$，再經 $S$ 從 $2$ 到 $3$，所以 $S\circ R=\{(1,3)\}$。
:::end
